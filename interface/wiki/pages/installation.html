Installation et mises à jour

K.NOVA s'installe dans le profil de l'utilisateur, sans droits d'administrateur Windows, et fonctionne ensuite hors ligne.

Installer

  1. Lancez l'installateur (Windows ou Linux), ou le kit hors ligne copié sur une clé USB.
  2. Choisissez les applications : BiRTEC, PDRTEC, AITEC. K.NOVA installe une seule fois ce qu'elles partagent : le moteur d'IA et son modèle, Java, le moteur BIRT, le pilote MySQL.
  3. Au premier lancement, ouvrez ou créez le fichier de connaissances (.ktec).

Mettre à jour

Portail › Installation et mises à jour : les nouvelles versions de K.NOVA et des applications, et ce qu'elles apportent. Internet n'est nécessaire que pour installer (sans kit) et mettre à jour : aucune donnée ne quitte le poste.

Les versions éco+

BiRTEC éco+ et PDRTEC éco+ sont des pages HTML seules, pour les postes sans K.NOVA : la pastille Eco+ d'une tuile les télécharge, déjà réglées pour le site (jamais de mot de passe dedans).
