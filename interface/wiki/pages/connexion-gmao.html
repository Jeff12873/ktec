Connexion à la GMAO

Comment les applications lisent la base de données de la GMAO : réglée une fois par l'administrateur, utilisée ensuite par tous, sans mot de passe à taper.

Pas à pas Admin

  1. Portail › Réglages › carte Connexion à la GMAO.
  2. Serveur (nom ou adresse), port (3306 en général), nom de la base.
  3. Compte de lecture et son mot de passe : utilisé par tout le monde, automatiquement. Choisissez un compte qui ne peut que lire : c'est la vraie protection.
  4. Compte d'écriture (facultatif) : seulement pour qu'AITEC crée ou modifie des FI, en mode administrateur, toujours après une simulation.
  5. Enregistrez : l'étiquette GMAO passe au vert sur tous les postes qui ouvrent ce fichier.

Questions fréquentes

« Utilisateur ou mot de passe refusé »

Le compte ou son mot de passe a changé côté base : l'administrateur les ressaisit dans les Réglages.

« Serveur injoignable »

Vérifiez que le poste est bien sur le réseau de l'entreprise (VPN compris). Si tous les postes sont touchés, le serveur ou le port a changé : voir l'administrateur.

BiRTEC signale que le compte peut modifier la base

Il n'écrit jamais, mais demandez au service informatique un compte en lecture seule : c'est la vraie protection.

Trucs et astuces

  • La connexion est commune à toutes les applications : un seul réglage, et le mot de passe n'est jamais demandé aux utilisateurs.
  • Sans connexion, beaucoup d'écrans restent consultables avec ce qui est gardé dans le fichier (structure, rapports, documents).
